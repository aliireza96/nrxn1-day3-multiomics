## H3K27me3 processed inputs

Place the processed H3K27me3 ChIP-seq assay inputs needed by
`scripts/analysis/04_h3k27me3.R` in this directory.

Expected files:

- `H3k27me3_chip_sig_allsamples.txt`
- `H3k27me3_chip_sig_allsamples_promoter.txt`
- `H3k27me3_chip_sig_females.txt`
- `H3k27me3_chip_sig_females_promoter.txt`

Optional:

- `macs2_peaks/` for the broadPeak files used to document the peak sources
